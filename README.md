# Caldera Bay

Caldera Bay is an original open-world crime game built for the make.fun gta6-01 competition.

Bounty: https://make.fun/bounty/gta6-01

## How to run
Serve the `game/` folder with any static file server (e.g., `python3 -m http.server 8000` or `npx serve game/`), then open `index.html` in your browser.

## Controls
- **Movement**: WASD
- **Interact**: E
- **Mug**: F
- **Weapon**: 1, 2, 3, 4, Tab
- **Radio**: Shift + R
- **Save**: F5
